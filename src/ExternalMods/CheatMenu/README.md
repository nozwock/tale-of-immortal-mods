## Original Description

Requirements:
- MelonLoader
- MelonLoader Dependencies

Instructions (Required):
1. Enable MelonLoader (MelonLoader v0.5.4 Open-Beta):
Ensure your game has MelonLoader enabled (version.dll is intact). To use Mods, enable UTF-8 in Windows:
- Navigate to Time & Language > Language & Region > Administrative language settings > Change system locale.
- Check Beta: Use Unicode UTF-8 for worldwide language support and restart your system.

2. Uninstall Old Cheat Menu:\
If you have the old Cheat Menu (Cheat UI) installed, uninstall it before installing this mod.
Don't worry—this mod shares the same structure, preserving your saves without triggering "missing mod" warnings.

3. Install the Mod:
- Subscribe and Restart the game to ensure everything works.

4. Restart After Accessing Mods:\
If you've recently accessed the in-game Mod section, restart the game before proceeding.

5. Fix Errors (If Necessary):\
If the mod doesn't function (e.g., UI issues), try this:
- Go to your \MelonLoader\Logs and see if you find an error related to this mod.
- Localize the mod by placing 'Mod_Mivopx' in to your GameName\ModExportData

6. Optimal Resolution:\
For the best experience, set your resolution to 1920x1080.

7. Finally, everything should work without any issues, and you can enjoy your gameplay. If not, I'm afraid it's up to you to troubleshoot and resolve the problem. Best of luck!
